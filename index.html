深入篇 · Transformer 逐步拆解

15从一个 token 到一个词表：先把形状算对12–18 min + 练习独立画出 Qwen3 的 token → embedding → decoder → logits，并算出 Q/K/V 的真实宽度。16亲手算一次 Attention：分数、权重、加权和12–18 min + 练习从小矩阵算出 attention 输出，区分 QKᵀ 分数、softmax 权重和最终向量。17因果遮罩：训练能并行，生成为什么要等12–18 min + 练习为 prefill、单步 decode 和带缓存的 chunk 写出正确的可见区间。18MHA、MQA、GQA：头共享了什么12–18 min + 练习给 query head 找到它使用的 KV head，并算清 GQA 节省哪一部分显存。19RoPE：旋转的是向量，保留的是相对位置12–18 min + 练习手算一个二维旋转，并证明 Q/K 共同平移后点积为何不变。20一个 decoder block：残差、RMSNorm 与 SwiGLU12–18 min + 练习把简洁的数学残差公式还原到 nano-vllm 的双变量 hidden_states / residual 实现。21KV cache：用等价实验理解“只算新 token”12–18 min + 练习解释为什么存 K/V 不存历史 Q，并验证完整前向与增量前向在误差容限内一致。22FlashAttention：不存整张分数表，如何仍然精确12–18 min + 练习用在线 softmax 的三个累积量解释 tiling，区分省 IO 与减少数学运算。23从 logits 到 token：温度、过滤与随机性12–18 min + 练习区分 logits、概率、top-p 和随机采样，解释相同种子为什么还不足以保证批不变。

深入篇 · nano-vllm 源码追踪

24跟踪一个请求：token 数、已缓存数与下一次计算12–18 min + 练习用状态表走完 chunked prefill 和两次 decode，定位每一次计数器更新。25从逻辑 token 到物理槽：块生命周期与前缀命中12–18 min + 练习手算 block_table / slot_mapping，并区分空闲、可复用缓存、正在被引用这三个状态。26Runner 是翻译层：变长 batch、静态地址与 CUDA Graph12–18 min + 练习从两条变长请求构造输入元数据，并说清 graph replay 固定什么、允许什么变化。

深入篇 · vLLM V1 运行时细节

27vLLM 调度账本：预算、在途工作与投机回退12–18 min + 练习正确计算一次混合调度的token预算，并在拒绝draft后修正computed计数。28vLLM KV 管理：hash 身份、free队列与淘汰12–18 min + 练习解释“已算hash”不等于“可共享KV”，并手算一次前缀命中与块池回收。29vLLM 执行层：六个token怎样变成三条请求的结果12–18 min + 练习手算GPU runner的关键数组，并建立不会混淆输入、输出、draft的测量口径。

深入篇 · DeepInfer 专项精读

30DeepInfer：公开引擎边界与 C++ 调度链12–18 min + 练习从Python请求跟踪到C++ batch，并区分公开离线引擎与完整线上服务所需组件。31MoE 与 EPLB：token 去哪里，专家副本放哪里12–18 min + 练习走通gate→dispatch→专家计算→combine，并手算一个冗余副本的放置与映射更新。32DSpark：验证预算、接受前缀与可复现边界12–18 min + 练习从逐位置置信度算累计接受率，再解释验证预算、KV回退与确定性条件。

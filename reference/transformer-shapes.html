一层的形状

X [N,H] → QKV [N,(Hq+2Hkv)d]
Q [N,Hq,d]；K,V [N,Hkv,d]
Q/K norm → RoPE → attention
O [N,Hq,d] → flatten [N,Hq·d] → Wo [N,H]
gate_up [N,2F] → SiLU(gate)⊙up [N,F] → down [N,H]

数学矩阵采用xW，W=[in,out]；PyTorch Linear.weight=[out,in]。Qwen3的Hq·d=2048，不等于H=1024。课15 · 课20。

attention / mask / online softmax

A = softmax(QKᵀ/√d + M)，O=AV
有p个历史token、新chunk长c：M[i,j]允许j≤p+i
m′=max(m,mᵦ)；α=exp(m−m′)；β=exp(mᵦ−m′)
l′=αl+βlᵦ；o′=αo+βoᵦ；最终O=o/l

分块独立softmax后平均会出错；无可见key的全−∞行也不能直接正常归一化。课17 · 课22。

KV字节与分页

标准KV bytes = 2 · L · B · T · Hkv · d · dtype_bytes
Qwen3-0.6B BF16：112 KiB / token；4096 token = 448 MiB
slot = block_table[t // block_size] · block_size + t % block_size

不含权重、激活、workspace、图缓冲、页尾空槽；FP8还可能有scale开销。单步缓存dense attention约O(t)，累计N步约O(N²)，不能说整段生成O(N)。课21 · 课25。
